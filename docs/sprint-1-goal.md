# Sprint 1: MVP интернет-магазина

**Дата:** 24.10.2026. **Формат:** индивидуальная имитация.
**Исполнитель:** Киреев Александр Сергеевич, М 25-ИО, @Reevan8899.

## Sprint Goal

Реализовать путь покупки: регистрация и вход, просмотр каталога, добавление
товаров в корзину, оформление заказа и поиск заказа в истории.

## Роли и задачи

В индивидуальной работе исполнитель совмещает PO, Scrum Master и Developer.
PO определяет истории и критерии; SM контролирует порядок работы;
Developer реализует пять фич и выполняет самопроверку.

| Ветка | User Story | Приёмка |
|---|---|---|
| feature/user-auth | Как покупатель, хочу зарегистрироваться и войти | Успешный вход; неверные данные отклоняются |
| feature/product-catalog | Как покупатель, хочу видеть товары и цены | Список из 3 товаров; поиск по ID |
| feature/cart | Как покупатель, хочу собрать корзину | Повторные добавления суммируются; корректный итог |
| feature/checkout | Как покупатель, хочу оформить доставку | Непустая корзина и адрес; уникальный заказ |
| feature/order-history | Как покупатель, хочу найти свой заказ | Поиск по ID и фильтр по минимальной сумме |

## Definition of Done

- Код запускается на Python 3.12.
- На каждую фичу есть unit-тесты, включая ошибки и граничные случаи.
- Ruff проходит; тесты проходят; покрытие не менее 80%.
- Выполнена и зафиксирована самопроверка PR; исправления подтверждены тестами.
- PR смержен в sprint-1; документация соответствует реализации.
- Финальная демонстрация подтверждает Sprint Goal.

## Отличия индивидуального формата

Независимые участники, их одобрения и обратная связь преподавателя не
имитируются вымышленными аккаунтами. По согласованию с исполнителем
независимое ревью заменено самопроверкой; в защите веток используются
обязательный PR, проверки CI и запрет force-push/удаления.
Требование методички об одном внешнем approval таким способом не выполнено.
